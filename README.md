# FabriCost PRO DEMO – Web versija

## Paleidimas

```bash
cd web_demo
pip install flask
python3 app.py
```

Tada atidarykite naršyklėje: http://localhost:5000

## Funkcijos

- Įkelkite vieną ar kelis projekto failus (PDF, Excel, Word, nuotraukos, DXF, ZIP ir kt.)
- Automatinė medžiagų specifikacijos ištraukimas su šaltiniais
- OCR skenuotiems dokumentams
- Konfliktų žymėjimas
- DEMO funkcijų demonstracija

## Pavyzdys

Galite naudoti pridėtus PDF failus iš sandėlio projekto (Verslo g. 17, Kumpių km.).
